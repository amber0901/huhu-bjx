# 互动复查与优化（第9版）

本轮按5–6岁孩子的操作视角逐姓复查：先听完诗，再出现对象、目标和结果都看得见的场景任务。26姓均已在本地浏览器实际操作完成；这属于成人模拟操作检查，还需在65寸华为一体机上让孩子试用。

## 统一体验

- 初始、朗诵中和暂停时只显示诗句与背景；朗诵实际结束后才出现互动对象。重播立即收起互动，读完恢复已有进度；重玩清空进度，回到等待听诗。播放失败不会提前解锁。
- 不再要求听完后额外找姓字，互动自动展开，并用小手示范第一步。灯泡会再次示范；闲置约7秒后重复提示。提示不会替孩子通关。
- 拖放任务同时支持点按部件完成放置，目标轮廓会发亮；长按任务松手暂停，续按继续。不增加跟读、额外讲解语音或可见文字说明。
- 诗句中与场景有关的已有词语短暂亮起，把诗意和画面联系起来；没有新增诗文。
- 音色、语速、两句正文、时间轴、已验收背景画与配乐沿用当前版本。新互动道具采用项目内矢量图，不增加在线模型调用或大型图片下载。

## 实际检查

- 26页均验证朗诵前互动隐藏、音频结束后出现、操作可完成。批量场景通过老师设置的真实进度条跳到音频结尾；王和周另行验证自然播放结束，未伪造媒体事件。
- 周验证重播隐藏、暂停仍隐藏、继续播放至自然结束后再出现；任意顺序拨弦可完成，完成后仍可自由弹琴。重玩恢复待播放状态。
- 张、江、尹、吴、邢验证真实拖动；廖错误拖放返回原位，灯泡只演示，不自动完成；郭点城墙内的山不会通过。
- 陈眉毛与胡子目标对齐；廖换成手边礼物轮廓；汪增加岸边与船上人物；吴修正禁用小船拦截太阳触摸；张、尹、吴的拖动行程对齐画面位置；松手时也处理最后落点。
- 邓的楼层大小可辨且能搭成完整城楼；肖的倒影与桥相接；于的最终人物头部不出界；邢最后印的是实际花朵。
- 自动化测试19项通过，素材结构检查26首通过。详细浏览器记录：[interaction-v9-browser.json](qa/interaction-v9-browser.json)。

## 试用时观察

目标是看一遍手势后能开始操作，且能从人物或物体的变化得到反馈。陈、尹、廖选句含较陌生的人物称谓；本轮用具体人物与动作降低操作门槛，但画面不能代替老师对古诗的解释。姓字在诗中可能表示人物、地名、颜色或物体，互动属于诗意／字义联想，不当作姓氏起源讲解。肖仍保留诗中xiào、姓氏xiāo的读音区别。

真实大屏上优先观察孩子是否愿意重玩、是否容易被手指遮住目标、长按是否疲劳。浏览器完成26项不能证明孩子已理解全部诗意。
