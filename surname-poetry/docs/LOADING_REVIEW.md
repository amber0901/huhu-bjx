# 加载与背景音乐优化

用户反馈公网设备需要等待十几秒，期间出现空画面、图片替代文字。本轮缩短请求链路并优先呈现当前诗画，不对实际设备的秒数作未经测量的保证。腾讯云当前入口端口由服务器 `.env` 配置，用户使用8090，Git更新不覆盖它。

## 当前行为

- 首页只读取26姓的简短名册。识别出姓氏后，在孩子确认前提前加载对应诗词iframe；确认时复用该页面，重写/返回时清理预载页面并停止音频。
- 诗词页请求 `/api/poem`，只返回当前一首及其时间轴。旧的全量素材接口保留兼容，但不再阻挡课堂诗画显示，也不会把全班时间轴写回目录对象。
- 每个入口的脚本合并成一份内容版本文件，取消诗词页7个模块、4层依赖的网络瀑布。脚本采用一年immutable缓存；HTML仍需校验，以便更新后使用新版本。JSON、HTML、CSS与脚本按Accept-Encoding协商Gzip，压缩与原文使用不同ETag，禁止gzip的请求仍返回原文。
- 先加载背景和文字，随后准备音频；图片未完成时不展示破图，网络错误时显示图标重试。声音仍在孩子点击后播放，预载页面不会自动发声。
- 原始24kHz WAV及时间轴保留不变，终端播放使用24kHz单声道96kbps MP3；所有转码都在素材制作电脑完成，Docker不需要ffmpeg。浏览器实测王姓MP3时长仍为5.271125秒。
- 课堂端使用时缓存当前素材，不在首页抢先下载全班资源；教师进入素材预览页时仍可准备完整缓存。缓存当前诗词不会删除其他姓氏缓存，只有完整清单成功缓存后才清理旧版本。普通HTTP继续使用浏览器长期缓存，HTTPS/localhost额外启用Service Worker。
- 背景音乐默认音量由45%降为35%（幅度降低约22%，约-2.18dB）；朗诵音量与已确认的音乐内容不变。老师仍可通过设置调节。

## 实测体积

| 项目 | 原来 | 当前 |
|---|---:|---:|
| 诗词页资料 | 全班70,500字节 | 王姓单首2,618字节；Gzip传输1,679字节 |
| 首页名册 | 完整目录 | 1,075字节；Gzip传输397字节 |
| 诗词脚本请求 | 7个模块、4层依赖 | 单份脚本；Gzip传输14,554字节 |
| 全班朗诵 | WAV共6,607,786字节 | 播放MP3共1,678,744字节，减少约75% |
| 全班运行诗画媒体 | 12,341,413字节 | 7,412,371字节，减少约40% |

大小记录见 `qa/loading-v1-sizes.json`。这些是字节数与本地功能验证，不能等同于真实网络加载时间。

## 验证与发布

16项自动测试和26份素材检查通过，覆盖单首API、简短名册、目录不被时间轴污染、Gzip协商与304、静态版本缓存、按需缓存不误删以及原有识别与互动。浏览器复查王/李/马/文背景、MP3播放与35%设置；王姓互动完成；重试图标与缺省图片隐藏正常。延迟测试服务模拟每个请求200ms、王背景1800ms，识别使用本机桩：确认前已开始预载，确认后页面可见，返回会移除iframe。没有调用真实识别收费接口。

浏览器记录：`qa/loading-v1-browser.json`；截图：`qa/loading-v1-wang.png`。本地验证不能替代65寸设备现场网络和扬声器验收。

修改前端源码后，在开发电脑执行 `npm ci`、`npm run build`、`npm test` 与 `npm run check:assets`。打包脚本固定使用esbuild 0.28.2，记录源码和产物哈希；Docker构建时检查打包文件新鲜度，不需要安装开发依赖。素材更改后仍先运行工坊的发布、压缩脚本。

服务器在 `surname-poetry/` 目录执行：

```sh
git pull --ff-only
docker compose up -d --build
curl --fail http://127.0.0.1:8090/api/health
```

更新后在设备上刷新页面一次。既有 `.env`、8090端口和课堂口令不需要更改。此记录不代表本机已构建Docker镜像或代替用户执行了服务器更新。
