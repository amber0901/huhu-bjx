## 真实模型联调

使用本地环境变量中的 TokenHub Key 调用 `hy-vision-2.0-instruct`。调用采用腾讯云官方 [图片理解](https://cloud.tencent.com/document/product/1823/136956) 的 Chat Completions 图片 Base64 格式，地址 `https://tokenhub.tencentmaas.com/v1/chat/completions`。没有将 Key 放入浏览器。

通过浏览器拖动在真实 Canvas 上写字，提交前由前端裁切笔迹、生成白底 512×512 PNG。四次实际调用：

这些是少量清晰笔迹样例，不是儿童手写准确率测评。仍需让孩子在实际设备上书写，评估歪斜、连笔、过小字、触控笔与手指遮挡等情况。

## 浏览器流程

- 首页空白时“写好了”、撤笔、重写禁用；写字后启用。撤去唯一一笔后恢复空白状态。
- 单点、过小笔迹在本地提示“再写大一点点”，不请求模型。
- 识别后先展示笔迹与汉字，由孩子确认；否认可重新书写。
- 诗词页只展示并朗读已验收的一联，题目和作者在后，无跟读；逐句高亮、原纯音乐与各姓互动接入正式素材。
- 诗词页内“再写一个姓”返回首页，清空上一轮笔迹、移除诗词页并停止音频。顶层页面不导航，保持全屏状态；测试中可从全屏诗词返回写字，再退出全屏。
- 1920×1080、1280×720 检查主要页面与互动。720p 首页无横向和纵向溢出，画布约 466×466px，提交按钮位于视口内。
- 3840×2160 增加字体、按钮和画布尺寸。首页画布约 1132×1132px，文档布局边界不溢出；王姓画面保持 16:9，约 2752×1548px，底部主要按钮仍在视口内。4K 外观与触控舒适度待实际 65 寸屏确认。
- 最终首页浏览器控制台无错误或警告。

## 可控异常测试

另在仅监听本机 8900 端口的独立测试进程中注入受控模型响应；不向腾讯云发请求，不在正式应用中提供模拟识别开关。检查后已停止测试进程并关闭测试标签。

- 错误课堂口令给出提示；正确口令进入写字页。
- 上游失败显示友好提示，保留笔迹并支持“再试一下”。
- 重试返回 unclear 时鼓励重写，不进入诗词页。
- 识别途中取消可返回修改；迟到结果不会把页面切回识别确认。
