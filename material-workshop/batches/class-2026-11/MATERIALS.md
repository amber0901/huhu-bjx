| 周 | 《听筝》唐·李端 | 欲得周郎顾， / 时时误拂弦。 | 周：拨响三根琴弦，让周郎转头听琴。诗中周郎听琴、顾盼。 |
| 徐 | 《定风波·莫听穿林打叶声》宋·苏轼 | 莫听穿林打叶声， / 何妨吟啸且徐行。 | 徐：按住诗人，陪他走过小路。徐行就是慢慢走的诗意联想。 |
| 王 | 《乌衣巷》唐·刘禹锡 | 旧时王谢堂前燕， / 飞入寻常百姓家。 | 王：把小燕子送到同字门牌的小屋。正文王字匹配，飞入百姓家。 |
| 文 | 《送梓州李使君》唐·王维 | 文翁翻教授， / 不敢倚先贤。 | 文：翻四页，看到文的四笔逐渐着墨。文翁讲学与文字学习的联想，不当字源。 |
| 何 | 《回乡偶书》唐·贺知章 | 儿童相见不相识， / 笑问客从何处来。 | 何：点脚印，让老人和孩子见面。儿童相见、问客来处。 |
| 张 | 《庐山谣寄卢侍御虚舟》唐·李白 | 庐山秀出南斗傍， / 屏风九叠云锦张。 | 张：拉小云朵，展开山水屏风。云锦张，张开画屏。 |
| 江 | 《宿建德江》唐·孟浩然 | 野旷天低树， / 江清月近人。 | 江：把江上月影拖到船边诗人附近。江清月近人。 |
| 陈 | 《送陈章甫》唐·李颀 | 陈侯立身何坦荡， / 虬须虎眉仍大颡。 | 陈：给陈伯伯贴虎眉和卷胡子。虬须虎眉描写陈侯外貌；人物称呼仍需老师介绍。 |
| 翁 | 《江雪》唐·柳宗元 | 孤舟蓑笠翁， / 独钓寒江雪。 | 翁：点鱼漂下竿，鱼咬钩后再提竿。蓑笠翁独钓。 |
| 邢 | 《茶中杂咏·茶瓯》唐·皮日休 | 邢客与越人， / 皆能造兹器。 | 邢：拉圆茶碗，再印一朵花。邢地工匠造茶瓯；地点背景不作为姓氏起源。 |
| 尹 | 《九日登望仙台呈刘明府》唐·崔曙 | 关门令尹谁能识， / 河上仙翁去不回。 | 尹：拉门闩，打开关隘送仙翁到河边。关门是关隘，令尹是人物称谓；开关隘为场景任务，不作词义或字源解释。 |
| 贺 | 《塞下曲·其四》唐·卢纶 | 野幕敞琼筵， / 羌戎贺劳旋。 | 贺：敲鼓，让三条彩带展开。贺有庆贺义，表现归来庆贺的场景，不展示战斗或饮酒。 |
| 李 | 《感遇·江南有丹橘》唐·张九龄 | 徒言树桃李， / 此木岂无阴。 | 李：把木和子拼成李，展开树荫。李字构形与树、此木岂无阴的诗句联想。 |
| 朱 | 《乌衣巷》唐·刘禹锡 | 朱雀桥边野草花， / 乌衣巷口夕阳斜。 | 朱：选朱红颜料，给桥边花涂色。朱红颜色义与朱雀桥边野草花的联想，不解释桥名来源。 |
| 肖 | 《再题文园狮子林十六景·其二·虹桥》清·弘历 | 石桥湖口长虹肖， / 来往都凭镜影中。 | 肖：把倒影拼到桥下，圆圆桥洞里游出小鱼。相肖表示相似，镜影指倒影；诗中肖读xiào、姓氏读xiāo。 |
| 雷 | 《无题·飒飒东风细雨来》唐·李商隐 | 飒飒东风细雨来， / 芙蓉塘外有轻雷。 | 雷：按住云朵，细雨浇开荷花。芙蓉塘外轻雷、细雨来。 |
| 马 | 《登科后》唐·孟郊 | 春风得意马蹄疾， / 一日看尽长安花。 | 马：带小马逐一走近花苞，看它们开放。马蹄疾、看尽长安花。 |
| 廖 | 《再次韵呈廖明略》宋·黄庭坚 | 物诚有之士则然， / 晚得廖子喜往还。 | 廖：先送书卷，再接朋友回赠的花。与廖子朋友往还；人物称呼需老师一句介绍。 |
| 邓 | 《邓州城楼》宋·陈与义 | 邓州城楼高百尺， / 楚岫秦云不相隔。 | 邓：把宽中窄三层搭好，屋顶升起旗子。邓州城楼高百尺。 |
| 汪 | 《赠汪伦》唐·李白 | 桃花潭水深千尺， / 不及汪伦送我情。 | 汪：按住岸边朋友挥手，送船慢慢离开。汪伦送我情与潭水送别。 |
| 刘 | 《再游玄都观》唐·刘禹锡 | 种桃道士归何处？ / 前度刘郎今又来。 | 刘：把刘郎沿旧脚印带回园门。刘郎今又来；不把菜花场景误画成桃花盛开。 |
| 于 | 《蜀道难》唐·李白 | 蜀道之难， / 难于上青天！ | 于：点亮云阶，让小人一步步上青天。难于上青天的登高意象。 |
| 洪 | 《观沧海》东汉·曹操 | 秋风萧瑟， / 洪波涌起。 | 洪：划海面或点秋叶，让三层浪涌起来。秋风与洪波涌起。 |
| 郭 | 《过故人庄》唐·孟浩然 | 绿树村边合， / 青山郭外斜。 | 郭：点亮村庄城墙外的青山。郭指城郭，青山在郭外，不作姓氏起源。 |
| 栗 | 《南邻》唐·杜甫 | 锦里先生乌角巾， / 园收芋栗未全贫。 | 栗：把树上的三颗栗果收进篮子。园收芋栗中的收栗果。 |
| 吴 | 《芙蓉楼送辛渐》唐·王昌龄 | 寒雨连江夜入吴， / 平明送客楚山孤。 | 吴：向上推太阳，天亮后点船送客。夜入吴到平明送客的时间与送别场景。 |

少见姓氏说明：陈、尹、贺、廖选句有生僻字，需要老师结合画面解释；没有为了耳熟能详而修改古诗原文或冒用标题、作者中的姓氏。肖保留原字，诗中表示相似读xiào，姓氏读xiāo。邢采用核对版本“邢客与越人，皆能造兹器”，不混用其他版本措辞。

《听筝》“周郎”联系听曲；《过故人庄》郭为城郭；《南邻》栗为果实。互动用诗意或字义联想，不将其包装为姓氏起源。
