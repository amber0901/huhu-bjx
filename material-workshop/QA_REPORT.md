## 画面

第二版减少写实细节与硬笔触，改为浅暖纸底、湿画法晕染、圆润形状。王姓画面为小燕子、桥边野花与夕阳下的人家；李姓为饱满橘子、柔软树叶和温暖橘园。两张图保留左侧阅读区，背景不带文字。

已在 1920×1080 的浏览器视口检查：王姓四句完整容纳，李姓十句以五联排列；标题、诗文、按钮和进度条可见。截图保存在 `preview/screenshots/wang-sync.jpg` 和 `preview/screenshots/li-sync.jpg`。实际图片不是原生 4K，诗文由独立 HTML 字体层显示。65 寸华为一体机尚未实测。

## 朗诵与时间轴

正式声音使用腾讯云 TTS 音色 101001，原始语速 -1，后期保调减速至 0.88 倍，并增加句间停顿；文件为 16 kHz、单声道、16-bit PCM WAV。原稿、服务端字级字幕和合成音素保存在各项目 `source/`。

发现并修正了《感遇》中“绿林”的默认多音字读法：明确指定“绿”为 `lv4`；“重深”的“重”指定 `chong2`。检查了“橘”`jv2`、“荐”`jian4`、“阴”`yin1`、“李”`li3`，以及《乌衣巷》的“王”`wang2`、“斜”`xie2`、“燕”`yan4`。服务使用 `v` 表示拼音 ü；这些是合成响应音素的核对结果。

时间轴由真实字级字幕合并，依据音频变速前后实测时长比例和实际静音帧数同步变换。未用等分时长或文字长度猜测。`release/timing.json` 与正式 WAV 配套；每句文字、顺序、最小间隔及音频边界检查通过。SSML 用法参考[腾讯云官方文档](https://cloud.tencent.com/document/product/1073/49575)。

额外试用了 403005 教师音色，原始试音留在王姓项目 `source/voice-auditions/`。该次响应未提供字级字幕，本轮正式包沿用已完成同步校准的 101001。

## 配乐和响度

两首分别使用 MiniMax Music v2.6 的纯音乐模式生成，提示词分别偏向温暖古巷与安静橘林，完整提示词在各项目 `prompts/music.txt`。取原曲 64 秒并做 3 秒交叉淡化，形成 61 秒循环；正式 MP3 为 44.1 kHz、双声道、192 kbps。

首次王姓配乐实际已生成，但客户端误按十六进制处理了 URL，未能保存首个下载地址；修复后重新生成了一次。修复后的脚本先保存完整响应，后续解析或下载失败不重新提交。失败记录及原始结果都保留在本地 `source/`，不进入部署包。

## 独立语音转写检查的边界

本地使用 MLX Whisper small，未给它提供诗词原文作为提示，也未向第三方上传音频。转写存在古诗同音异字与漏字，严格文字匹配没有全部通过，保留了原始结果。例如王姓将“旧时”写成“就是”、“飞入”写成“肥入”；李姓将“丹橘”写成“丹菊”，并漏转了“伊”等字。引导语把“啦”写成“了”，也不算严格一致。

因此没有把 ASR 文字相似度当作发音的完整认证。指定多音字采用合成音素交叉检查，配合真实音频供试听。旧版、试音和其他本地模型的实际转写保留在 `source/`，未把失败结果覆盖成成功。

## 浏览器操作结果

通过本地浏览器实际操作并读取音频元素状态，确认了：

- 切换李、王时更换相应背景、诗文和音频。
- 朗诵与音乐同时播放；点击王姓第三句时，实际播放位置约 7 秒，当前高亮为“旧时王谢堂前燕”。
- 点击李姓第九句可跳转至约 20.6 秒，高亮“徒言树桃李”；暂停时朗诵和音乐均暂停，继续后均恢复。
- 李姓朗诵与 6.741 秒引导语结束后，进入自主朗读状态，完整十句保留，显示“我读完啦”。等待结束后自动显示鼓励语并停止配乐。
- 检查时浏览器未记录 console error / warn。

本地预览不录音，不判断孩子是否实际朗读，不做识别评分。正式手写识别和课堂设备集成不属于本轮素材验收。

发布后 `npm run check:assets` 通过，两首共 12 个正式文件，合计 8,660,468 字节。临时启动基础 HTTP 服务，确认健康检查、两首目录、十项资源、时间轴读取和 WAV 的 `206` 分段请求正常。已检查待提交文件，未命中本地三项凭据的值。
