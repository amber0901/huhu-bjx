# 样板统一画风

彩色水墨与儿童绘本质感，浅暖纸底，柔和青绿、鹅黄和淡橘色。画面明亮、安静、亲切；山水植物简洁可辨，人物表情自然。使用淡墨层次和留白，避免阴森、强烈对比、复杂战争场景和密集纹理。

第二版以幼儿绘本为准：形状圆润，橘子饱满，小燕子亲切可爱，屋檐和树干采用柔和曲线。使用轻柔湿画法、边缘晕染与少量纸纹，减少细碎写实细节、尖锐枯笔、厚重墨块和成人山水画的肃穆感。保留水墨的通透感。

背景横屏 16:9，优先按 3840×2160 方向制作。中央偏左保留低细节阅读区，重要人物或树木放在画面右侧或两边；允许前端在阅读区叠加轻薄底色。实际导出尺寸在制作时核对，不以提示词代替尺寸验收。

背景中不绘制诗文、标志、按钮和水印。诗文由应用真实文字层排版，便于高亮、缩放和动画。不同诗歌沿用同一套色调与材质。

本轮最终背景使用各项目 `prompts/background-v2.txt`，实际像素均为 1672×941，接近 16:9。预览文字为独立 HTML 字体层；图片并非原生 4K。后续在 65 寸实机上检查观看距离与缩放效果。
